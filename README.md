# Campus Canteen Demand Analysis

**Data Mining and Analytics Lab Project**

## Project Overview

This project focuses on analyzing food demand patterns across three campus food outlets: Campus Canteen (Snackers), Domino's, and Nescafe.

The aim is to understand students' food preferences, spending habits, visiting frequency, and waiting times, while also studying canteen owners' experiences with peak hours, customer demand, and inventory management.

## Objectives

- Analyze student preferences and canteen visiting patterns.
- Identify peak demand periods and popular food items.
- Study spending habits and waiting times.
- Apply data mining techniques to discover meaningful patterns.
- Provide practical recommendations for inventory and demand management.

## Tools and Technologies

- **Language:** R
- **IDE:** RStudio
- **Libraries:** ggplot2 and other R packages used in the analysis
- **Data Source:** Student and canteen owner surveys

## Methodology

1. Data collection through Google Forms
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Statistical analysis and correlation analysis
5. K-means clustering
6. Data visualization and interpretation
7. Demand-related insights and recommendations

## How to Run

1. Download or clone this repository.
2. Open `Campus_Canteen_DMA.R` in RStudio.
3. Install the required R libraries.
4. Update dataset file paths if necessary.
5. Run the script to view the analysis and visualizations.

## Conclusion

The project demonstrates how data mining techniques can be applied to real-world campus food services. The findings can help canteen owners better understand student demand, prepare for busy periods, and improve stock planning.

## Future Scope

Future improvements may include collecting data over longer periods, integrating actual sales records, developing predictive demand models, and creating interactive dashboards for canteen owners.
